Mini Guide: What you’re seeing

This page uses layered gradients for the aurora background, an animated “snow” overlay, and inline SVG shapes for the penguin character. The mood button swaps the vibe by adjusting CSS variables.

1) AuroraFixed, blurred color drift that sets the mood.
2) Stage + SVGPenguin and icy paths are drawn with scalable vector shapes.
3) MotionFloat + bounce animations with reduced-motion support.
4) GalleryThree visual tiles with decorative “spark” SVGs.
